## How to use

1. Read `study_plan.md` for the day-by-day schedule.
2. For each problem, **try it yourself first** (25–30 min cap), then read the solution.
3. Re-implement the solution from memory the next morning before moving on.
4. Use `cheatsheet.md` for the last 30 minutes before each session.
